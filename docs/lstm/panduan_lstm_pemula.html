Bagian 4 · Cara Kerja Model

Cara Kerja Otak LSTM & 3 Rem Anti-Hafalan (Overfitting)

LSTM membaca 46 bar terakhir (2 sesi penuh XAUUSD: seluruh sesi kemarin + sesi hari ini hingga t*) satu per satu sambil membawa memori. Klik tombol di bawah untuk melihat peran 3 gerbangnya:

🧹 1. Forget Gate

Membuang ingatan lama yang sudah basi (misalnya fluktuasi kecil di awal sesi kemarin yang tidak relevan lagi dengan kondisi saat menyentuh level).

📝 2. Input Gate

Menyimpan informasi penting dari candle saat ini (misalnya harga menjauh dari EMA50, volatilitas meningkat, muncul wick penolakan + lonjakan volume jam-sama).

🎯 3. Output Gate → Linear(3)

Di bar terakhir t*, ringkasan memori h_T (32 angka) dilewatkan Dropout(0,3) lalu Linear(3) → 3 logits → Rev, Cont, Netral.

3 Rem Anti-Overfitting di arsitektur.py

🎲 1. Dropout (30%)

30% neuron dimatikan acak di tiap batch saat training agar LSTM tidak bergantung pada satu jalur hafalan saja.

🛑 2. Early Stopping (85% / 15%)

Data latih dibelah kronologis: 85% awal untuk update bobot, 15% ujung untuk cek Log-Loss tiap epoch (patience = 12). Bobot dikembalikan ke epoch terbaik tanpa pernah mengintip tahun ujian.

🌱 3. Ensemble 5 Seed Kunci-1

Setiap konfigurasi dilatih 5 kali (seed 20261119..20261123, num_threads = 1), lalu logits dirata-rata agar hasil stabil & 100% deterministik.

🧪 Studi Kasus Mini PyTorch (Bisa Dihitung di Kepala!)

1. Input (1 × 2 × 2): Jam 1 = [f1=+2, f2=0] (naik kuat) → Jam 2 (t*) = [f1=−1, f2=+3] (ditolak keras!) 2. nn.LSTM baca 2 jam: Awal [0,0] → Jam 1 [+2, 0] → Jam 2: Forget 50% (+2×0,5 − 1 = 0), Input tolak (+3) → h_T = [0, +3] 3. nn.Dropout(0,3): Saat evaluasi tidak ada yang dimatikan → tetap [0, +3] 4. nn.Linear(2 → 3): Rev = (−1·0 + 1·3) = +3 | Cont = (1·0 − 1·3) = −3 | Net = 0 → Logits = [+3, −3, 0] 5. Softmax (Σ = 100%): e³≈20, e⁻³≈0,05, e⁰=1 (total≈21) → Rev 95% · Cont 0,2% · Net 4,8% 6. Belajar (85% saja!): Jika salah (misal tebak Rev cuma 10%), Loss = −ln(0,10) = 2,30 → loss.backward() + AdamW naikkan bobot!

Bagian 8 · Tahap 5 (RM-26)

RM-26: Kalibrasi τ — Temperature Scaling di calib 2024 (227 Event)

Model neural network sering akurat mengurutkan kelas, tetapi terlalu percaya diri (overconfident) dalam angka peluangnya. Di RM-26, kita memuat 5 checkpoint RM-25 dalam mode beku (eval(), tanpa melatih ulang bobot) dan mencari tepat 1 angka skalar suhu τ pada data 2024 agar probabilitasnya terkalibrasi jujur: p_cal = Softmax(mean_logits / τ).

RM-25: 5 .pt + scaler → RM-26: Cari τ pada calib 2024 (227 event) → RM-27: Keputusan R → 🔒 Kunci-2
Analogi Pemula — Termometer Kepercayaan Diri (τ):
Bayangkan model berkata "72% pasti Continuation!", padahal kenyataannya di lapangan hanya benar 50% (terlalu pede!). Membagi logits dengan suhu τ > 1 (di kita ketemu τ = 1,2375) akan "mendinginkan" tebakan ekstrem itu menjadi ~64% agar jujur sesuai fakta — tanpa pernah mengubah kelas mana yang nomor #1 (ranking tetap 100% sama) dan tanpa mengubah 1 pun bobot LSTM! Sebaliknya, bila τ < 1, peluang ditajamkan; bila τ = 1, tidak berubah.

Bagian 9 · Tahap 6 (RM-27)

RM-27: Aturan Keputusan — Peluang Terkalibrasi → Reversal / Continuation / Abstain & realized_R

Setelah memiliki probabilitas yang jujur dari RM-26 (p_rev, p_cont, p_net), sistem pendukung keputusan (DSS) harus menjawab pertanyaan praktis: "Ambil Reversal, ambil Continuation, atau lebih baik Abstain (tidak bertransaksi)?" Jawabannya bukan sekadar memilih peluang terbesar, melainkan menghitung Nilai Harapan (Expected Value) dalam satuan R.

RM-26: p_cal (τ = 1,2375) → RM-27: Hitung E_rev, E_cont & realized_R → 🔒 Kunci-2
Kenapa Tidak Cukup Memilih Kelas dengan Peluang Terbesar? (Asimetri Risiko–Imbal Hasil!)
Dengan label Kunci-1 (a = 2, b = 1):
  • Posisi Reversal: menang dapat +2,0R, kalah rugi −1,0R, Netral rata-rata di dev dapat m_rev = +0,5627R (dari 385 event Netral dev).
  • Posisi Continuation: menang hanya dapat +0,5R (b/a), kalah rugi −1,0R, Netral rata-rata di dev dapat m_cont = −0,2813R = −0,5·m_rev.
Karena menang Reversal dibayar 4× lebih besar daripada menang Continuation, peluang 45% Reversal bisa sangat positif (+0,48R), sedangkan peluang 61% Continuation masih impas (0R)!

Rumus Nilai Harapan & 3 Zona Keputusan (δ = 0,1R)

Nilai Harapan Reversal: E_rev = (+2)·p_rev + (−1)·p_cont + (+0,5627)·p_net Nilai Harapan Continuation: E_cont = (−1)·p_rev + (+0,5)·p_cont + (−0,2813)·p_net = −0,5 · E_rev Aturan Ambang Utama (δ = 0,1R): • E_rev ≥ +0,10R → Reversal → realized_R = R_rev (+2,0R / −1,0R / R_netral) • −0,20R < E_rev < +0,10R → Abstain → realized_R = 0,0R (tidak masuk pasar) • E_rev ≤ −0,20R (E_cont ≥ +0,1) → Continuation → realized_R = R_cont (+0,5R / −1,0R / R_netral)
